# Astra Project Guidelines & Agent Rules

## 1. Collaboration & Role Division
- **User Focus**: Specifies features, business requirements, backend logic, data models, and system flows.
- **Agent Focus**: Fully responsible for designing and implementing high-polish, production-grade, beautiful Frontend UI/UX, animations, styling, and interactions without requiring the user to micro-manage visual details.

## 2. Frontend UI/UX Standards
- **Aesthetic Quality**: Modern, clean, and futuristic dark theme with cosmic accents (deep purples, subtle indigos, soft neon glows, frosted glass cards, rounded borders).
- **Typography & Layout**: High contrast, crisp hierarchy, balanced white space, and responsive scaling across Android and iOS screens.
- **Micro-Interactions & Animations**:
  - Use smooth physics-based / spring animations for transitions, tap effects, and state updates.
  - Subtle glowing or pulsing effects for live indicators (presence, distance updates, active call states).
  - Fluid bottom sheets, animated tabs, and interactive card expansions.
  - Never generate plain, flat, or generic default Material layouts.

## 3. Communication Style
- Always communicate in **English or Hinglish** as per user preference.
